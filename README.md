# 🗑️ SMART-TRASH-PROJETUTS

**EcoBatam IoT** adalah platform monitoring tempat sampah pintar berbasis real-time yang dirancang khusus untuk menangani permasalahan limbah di wilayah pesisir Tanjung Uma, Batam. Proyek ini dikembangkan menggunakan Framework **Laravel 11** untuk memenuhi tugas UTS Mata Kuliah Pemrograman Web Framework.

---

## 🚀 Fitur Utama
- **Premium Dashboard**: Visualisasi data telemetri menggunakan Chart.js dengan desain Modern Glassmorphism.
- **Real-time Analytics**: Monitoring kapasitas sampah (0-100%) dengan indikator warna dinamis (Merah/Kuning/Hijau).
- **Node Management (CRUD)**: Fitur untuk mendaftarkan titik (node) sensor baru ke dalam database.
- **Expert IoT Connectivity**: Tersedia REST API endpoint untuk integrasi data langsung dari perangkat hardware (ESP32/Arduino).
- **Responsive Sidebar**: Navigasi antar halaman (Dashboard, Network Nodes, & Analytics) yang fungsional.

---

## 🛠️ Tech Stack
- **Backend**: Laravel 11 (PHP 8.x)
- **Database**: MySQL
- **Frontend**: Bootstrap 5, Chart.js, Inter Fonts
- **API Protocol**: JSON via RESTful API
